# Fonts

Used to draw the engraving on the LED face of the top frame (`housing/branding.py`). All are under the
SIL Open Font License 1.1 (license text next to each font).

| File | Font | Used for |
|---|---|---|
| `Parisienne-Regular.ttf` | [Parisienne](https://fonts.google.com/specimen/Parisienne) | the *Lastdrop* name |
| `GeistMono-400.ttf` | [Geist Mono](https://github.com/vercel/geist-font), fixed at weight 400 | default font for the engraved text lines (no text uses it now) |
| `Geist-600.ttf` | [Geist](https://github.com/vercel/geist-font), fixed at weight 600 | taflev |
| `InstrumentSerif-Italic.ttf` | [Instrument Serif](https://github.com/Instrument/instrument-serif) | .com |

The Geist files are fixed-weight instances of the variable fonts, made with the `fontTools` instancer.
